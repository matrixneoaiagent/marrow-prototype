# Synthetic recording corpus

Everything under `recordings/` is generated by `marrow/synth.py`.  No real
person, movement, text, audio or camera data is present.  The recordings are
released under CC0-1.0.

* 372 sessions, seed `20261108`, reproducible with `python3 main.py --regenerate`.
* Three input styles: `pointer_keyboard`, `slow_pointer_dictation`,
  `switch_onscreen`.
* Each style has an owner, a same-style alternate, a same-style stranger, and
  two mimic variants.  Every identity has rested and tired sessions.
* Train / validation / test splits are in the manifest and in the header
  `labels` object.  The detector never reads `labels`.
* Text content is incidental original vocabulary; the detector uses only the
  length and timing of a text event.  `text_len` can replace `text` for a
  content-free recording.

The manifest is `manifest.json`.  Paths in it are relative to this directory.
`SHA256SUMS` records every generated recording; verify with
`cd data && sha256sum -c SHA256SUMS`.
